# Lab — ICMP Packet Analysis with Wireshark

## Objective

Capture an ICMP exchange and explain the packet fields and network flow.

## Environment

- Workstation: Windows
- Capture tool: Wireshark
- Target: `8.8.8.8`
- Authorization: Personal/local system

## Procedure

1. Start Wireshark on the active network interface.
2. Start a capture.
3. Apply the display filter:

```text
icmp
```

4. Generate ICMP traffic:

```powershell
ping 8.8.8.8
```

5. Stop the ping with `Ctrl+C`.
6. Select an Echo Request and its Echo Reply.
7. Record source, destination, ICMP type/code, TTL, sequence number, and timing.

## Analysis

### Echo Request

- Source IP: Local system
- Destination IP: `8.8.8.8`
- Protocol: ICMP
- ICMP Type: `8` — Echo Request
- ICMP Code: `0`
- TTL: Record the value observed in the capture

### Echo Reply

- Source IP: `8.8.8.8`
- Destination IP: Local system
- Protocol: ICMP
- ICMP Type: `0` — Echo Reply
- ICMP Code: `0`
- TTL: Record the value observed in the capture

## Security Relevance

ICMP is useful for connectivity troubleshooting and network visibility. Packet analysis is also a foundational SOC skill because analysts can inspect network traffic when investigating alerts or suspicious behavior.

## What I Learned

- How ICMP Echo Request/Reply works.
- How to identify source and destination IP addresses.
- How to inspect ICMP fields in Wireshark.
- ICMP does not use TCP/UDP ports.
