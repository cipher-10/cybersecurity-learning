Lightweight security monitoring platform.

- Sigma rule matching
- MITRE ATT&CK tagging
- AI-assisted alert triage

## Security Log Analyzer

Python utility that parses security logs, extracts suspicious events and produces a concise investigation report.

**Skills demonstrated:** Python, regex, parsing, IOC extraction, defensive analysis.

## Web Security Lab Reports

A collection of authorized web-security exercises with reproducible methodology, evidence and remediation.

## Threat Intelligence Notes

Structured analysis of public threat intelligence and OSINT sources, emphasizing source quality, indicators, context and defensive action.

## Project Standard

Every project should contain:

- Problem statement
- Architecture

- Source code
