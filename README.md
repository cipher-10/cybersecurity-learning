# Cybersecurity Learning

A structured, hands-on cybersecurity learning portfolio by **Om (cipher-10)**.

## Learning Path

```text
Foundations → Networking → Linux/Windows → Security Fundamentals
→ SOC / Blue Team → Web Security / VAPT → Forensics → Cloud
→ Python Security Automation → Projects → Job Preparation
```

## Structure

- `01-foundations` — security concepts and terminology
- `02-networking` — TCP/IP, ports, DNS, HTTP, packet analysis
- `03-linux` — Linux administration and security
- `04-windows` — Windows, PowerShell and security logs
- `05-security-fundamentals` — authentication, cryptography and vulnerabilities
- `06-soc-blue-team` — SIEM, detection and incident response
- `07-web-security` — OWASP and authorized web-security labs
- `08-vapt` — reconnaissance, enumeration, exploitation and reporting
- `09-digital-forensics` — evidence and forensic analysis
- `10-cloud-security` — AWS/Azure security fundamentals
- `11-python-security` — scripting and automation
- `12-labs` — practical lab write-ups
- `13-projects` — portfolio projects
- `14-certifications` — CEH, CHFI, CCNA and future certifications
- `15-job-preparation` — resume, interviews and applications

## Documentation Standard

Each topic should show **Concept → Tools/Commands → Lab → Evidence**.

The objective is to demonstrate practical ability, not just collect notes or certificates.

## Portfolio Projects

- **SENTINEL-X Lite** — lightweight security monitoring and detection platform.
- **Security Log Analyzer** — Python log parsing and suspicious-event detection.
- **Web Security Lab Reports** — reproducible authorized security exercises.
- **Threat Intelligence Notes** — structured OSINT and threat-analysis workflows.

## Lab Safety

Offensive-security work is limited to systems I own or environments where I have explicit authorization, such as local virtual machines and training platforms.
